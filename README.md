# bergmirror

A small badge for repositories that are primarily developed on [Codeberg](https://codeberg.org) and mirrored to GitHub.

## Badge

![Codeberg → GitHub mirror](https://ixxie.codeberg.page/bergmirror/badge.svg)

## Usage

Add to your README:

```markdown
[![Codeberg → GitHub mirror](https://ixxie.codeberg.page/bergmirror/badge.svg)](https://codeberg.org/ixxie/<repo>)
```

The badge links back to the canonical Codeberg repository.
